Rozdział 0 Podstawy Filozoficzne

Geneza, Zakres i Paradygmat Homo Rationalis

Teoria gier narodziła się na styku czystej matematyki i ekonomii. Od prac Ernsta Zermelo (1913) badającego skończoność partii szachowych, poprzez formalizację Johna von Neumanna (1928) i fundamentalne dzieło Theory of Games and Economic Behavior (von Neumann & Morgenstern, 1944), aż po rewolucję Johna Nasha (1950-1951), teoria dostarcza ścisłego języka do analizy interakcji strategicznych.

„Mówiąc krótko, teoria gier i teoria ekonomii zajmują się interaktywnym zachowaniem Homo rationalis - człowieka racjonalnego. Homo rationalis to gatunek, który zawsze działa zarówno celowo, jak i logicznie, posiada ściśle określone cele, jest motywowany wyłącznie pragnieniem zbliżenia się do tych celów tak bardzo, jak to możliwe, i posiada zdolności kalkulacyjne wymagane, aby to uczynić.”
- Robert Aumann (1985, s. 35)

Gry Kooperacyjne

Zakładają możliwość bezpośredniej komunikacji, formowania trwałych koalicji i zawierania prawnie wiążących umów (binding agreements). Wykorzystywane m.in. do analizy systemów głosowania, wartości Shapleya i sprawiedliwego podziału kosztów.

Gry Niekooperacyjne (Zakres Podręcznika)

Analizują sytuacje, w których gracze nie mogą się komunikować lub porozumienia nie mogą być prawnie egzekwowane (np. zakaz karteli i zmów cenowych w prawie antymonopolowym). Wszelkie porozumienia muszą być samoegzekwujące się (self-enforcing).

Część I • Rozdział 1 Strategic-Form Ordinal Games

Gry Porządkowe w Postaci Strategicznej

1.1. Ramka gry a gra (Game Frame vs Game)

Bonanno kładzie fundamentalny nacisk na rozróżnienie ramki gry od samej gry. Ramka gry w postaci strategicznej to czwórka:

$$\langle I, (S_1, S_2, \dots, S_n), O, f \rangle$$

gdzie $I = \{1, \dots, n\}$ jest zbiorem graczy, $S_i$ zbiorem strategii gracza $i$, $S = S_1 \times \dots \times S_n$ zbiorem profili strategii, $O$ zbiorem rezultatów fizycznych, a $f: S \to O$ funkcją przypisującą profilowi strategii rezultat. Dopiero dodanie preferencji porządkowych każdego gracza $\succsim_i$ nad zbiorem rezultatów $O$ tworzy grę. Preferencje muszą być zupełne ($\forall o, o': o \succsim_i o' \lor o' \succsim_i o$) oraz przechodnie ($o \succsim_i o' \land o' \succsim_i o'' \implies o \succsim_i o''$). Gdy preferencje reprezentujemy funkcją użyteczności $U_i: O \to \mathbb{R}$, otrzymujemy zredukowaną postać gry z funkcją wypłat $\pi_i(s) = U_i(f(s))$.

1.2. Dominacja ścisła i słaba (Strict & Weak Dominance)

Niech $s_{-i} \in S_{-i}$ oznacza wektor wyborów wszystkich graczy poza graczem $i$.

  • Ścisła dominacja: Strategia $a$ ściśle dominuje $b$, jeśli $\forall s_{-i} \in S_{-i}: \pi_i(a, s_{-i}) > \pi_i(b, s_{-i})$.
  • Słaba dominacja: Strategia $a$ słabo dominuje $b$, jeśli $\forall s_{-i}: \pi_i(a, s_{-i}) \ge \pi_i(b, s_{-i})$ oraz $\exists \bar{s}_{-i}: \pi_i(a, \bar{s}_{-i}) > \pi_i(b, \bar{s}_{-i})$.
  • Równoważność: Strategie $a$ i $b$ są równoważne, gdy dają identyczne wypłaty w każdym stanie rywali: $\forall s_{-i}: \pi_i(a, s_{-i}) = \pi_i(b, s_{-i})$.

Strategia jest ściśle dominująca, gdy ściśle dominuje każdą inną strategię danego gracza. Może istnieć co najwyżej jedna taka strategia. W klasycznym Dylemacie Więźnia (Prisoner's Dilemma) strategia zdrady jest ściśle dominująca dla każdego gracza, co prowadzi do równowagi w strategiach ściśle dominujących, która jest ściśle gorsza w sensie Pareto od wzajemnej współpracy.

Twierdzenie 1.1 • William Vickrey (1961)
Aukcja Drugiej Ceny (Vickrey Auction)

W zapieczętowanej aukcji drugiej ceny, jeżeli oferent $i$ jest egoistyczny i chciwy (ocenia wynik jako $v_i - p$ przy wygranej i 0 przy przegranej), wówczas zgłoszenie oferty równej własnej wycenie: $$b_i = v_i$$ jest strategią słabo dominującą.

Dowód: jeśli rywal zaoferuje $b_{\max} \le v_i$, oferta $v_i$ wygrywa i płaci $b_{\max} \ge 0$. Każda inna wygrywająca oferta płaci to samo, a niższa oferta ryzykowałaby utratę opłacalnego przedmiotu. Jeśli $b_{\max} > v_i$, wygrana przyniosłaby ujemną wypłatę $v_i - b_{\max} < 0$.

Twierdzenie 1.2 • Edward Clarke (1971)
Mechanizm Pivotowy (Clarke Mechanism)

Projekt publiczny o koszcie $C$ i udziałach kosztowych $c_i$ jest efektywny, gdy $\sum v_i > C$. Uczestnik $i$ jest pivotowy, gdy jego obecność zmienia decyzję społeczną. Płaci on wówczas podatek: $$t_i = \left| \sum_{j \ne i} w_j - \sum_{j \ne i} c_j \right|$$ Prawdomówne zgłoszenie wyceny ($w_i = v_i$) jest strategią słabo dominującą!

1.5. Procedury eliminacji iteracyjnej (IDSDS vs IDWDS)

IDSDS (Iterated Deletion of Strictly Dominated Strategies): W każdym kroku usuwamy wszystkie strategie ściśle zdominowane. W grach skończonych procedura zawsze zbiega do podzbioru $G^\infty$ w skończonej liczbie kroków. Kolejność usuwania strategii nie ma żadnego wpływu na wynik końcowy (Remark 1.5).

IDWDS (Iterated Deletion of Weakly Dominated Strategies): Dopuszcza usuwanie strategii słabo zdominowanych. Uwaga: kolejność eliminacji wpływa na rezultat! Aby procedura była jednoznaczna, Bonanno definiuje IDWDS jako jednoczesne usunięcie w każdym kroku wszystkich strategii słabo zdominowanych.

1.6. Równowaga Nasha i Konkurencja Cournota

Profil strategii $s^* = (s_1^*, \dots, s_n^*)$ jest Równowagą Nasha, jeśli dla każdego gracza $i$: $$\forall s_i \in S_i: \quad \pi_i(s_i^*, s_{-i}^*) \ge \pi_i(s_i, s_{-i}^*)$$ Każdy gracz wybiera najlepszą odpowiedź (best reply) na wybory rywali. Dla gier o ciągłych zbiorach strategii, pionierski model Augustin Cournota (1838) rozważa duopol o popycie $P(Q) = a - b(q_1 + q_2)$ i kosztach $C_i(q_i) = c \cdot q_i$. Maksymalizacja zysków $\frac{\partial \pi_i}{\partial q_i} = a - c - 2bq_i - bq_j = 0$ prowadzi do unikalnej równowagi: $$q_1^* = q_2^* = \frac{a - c}{3b}, \quad P^* = \frac{a + 2c}{3}, \quad \pi_1^* = \pi_2^* = \frac{(a - c)^2}{9b}$$

Część I • Rozdział 2 Dynamic Games with Perfect Information

Gry Dynamiczne o Doskonałej Informacji i Indukcja Wsteczna

2.1. Drzewa decyzyjne i algorytm wstecznej indukcji

Gra w postaci ekstensywnej o doskonałej informacji jest reprezentowana przez ukorzenione drzewo skierowane. W każdym węźle decyzyjnym dokładnie jeden gracz podejmuje decyzję, znając pełną historię wszystkich dotychczasowych posunięć.

Algorytm indukcji wstecznej (Definicja 2.3): Zaczynając od węzłów przedostatnich (penultimate nodes), których bezpośrednimi następcami są wyłącznie węzły terminalne, gracz wybiera akcję maksymalizującą jego własną wypłatę. Węzeł decyzyjny zostaje zastąpiony wektorem wypłat wybranego następcy. Procedura powtarzana jest wstecz aż do osiągnięcia korzenia.

2.3. Pojęcie strategii: Kompletny plan kontyngentny

Definicja 2.4: Strategia w grze o doskonałej informacji to lista wyborów, po jednym dla każdego węzła decyzyjnego tego gracza, nawet takiego, który nie zostanie osiągnięty w trakcie faktycznej rozgrywki! Ta cecha wprowadza formalną nadmiarowość (redundancy), lecz jest kluczowa dla analizy gróźb poza ścieżką równowagi.

Twierdzenie 2.1: Każde rozwiązanie indukcji wstecznej jest równowagą Nasha powiązanej postaci strategicznej. Jednak zbiór równowag Nasha postaci strategicznej jest z reguły ściśle szerszy i zawiera równowagi oparte na niewiarygodnych groźbach (Incredible Threats).
Paradoks Seltena (1978)
Gra w Sieć Sklepów (Chain Store Paradox)

Monopolista operuje w $m$ miastach. W każdym mieście pretendent rozważa wejście. Intuicja nakazuje walczyć z pierwszymi pretendentami, by zbudować reputację. Jednak w indukcji wstecznej w ostatnim mieście monopolista na pewno ulegnie (ponieważ walka przynosi zysk 0 zamiast 2). Wsteczna indukcja rozwija ten argument aż do miasta 1: monopolista ulega we wszystkich miastach!

Twierdzenia 2.2 i 2.3 • Zermelo (1913)
Determinizm Gier Dwuosobowych

W każdej skończonej grze dwuosobowej typu wygrana-przegrana o doskonałej informacji, jeden z graczy posiada strategię wygrywającą. Dla gier dopuszczających remis (szachy, warcaby, kółko i krzyżyk): albo Gracz 1 ma strategię wygrywającą, albo Gracz 2 ma strategię wygrywającą, albo obaj gracze posiadają strategie gwarantujące co najmniej remis!

Część I • Rozdział 3 General Dynamic Games & SPE

Ogólne Gry Dynamiczne, Podgry i SPE

3.1. Zbiory informacyjne i doskonała pamięć (Perfect Recall)

Gdy gracz podejmuje decyzję nie wiedząc, w którym dokładnie węźle drzewa się znajduje, węzły te łączone są w zbiór informacyjny $\mathcal{D}_i$. Definicja 3.1 nakłada fundamentalny warunek doskonałej pamięci (Perfect Recall): gracz w każdym momencie pamięta wszystkie informacje, które posiadał w przeszłości, oraz wszystkie decyzje, które sam podjął.

3.3 - 3.4. Podgry właściwe i Równowaga Doskonała w Podgrach (SPE)

Podgra właściwa (Definicja 3.3): Część drzewa rozpoczynająca się w pojedynczym węźle decyzyjnym (różnym od korzenia), która nie rozcina żadnego zbioru informacyjnego.

Definicja 3.5 (Reinhard Selten, 1965): Profil strategii $s$ jest równowagą doskonałą w podgrach (Subgame-Perfect Equilibrium - SPE), jeśli:
  1. $s$ jest równowagą Nasha całej gry, oraz
  2. dla każdej właściwej podgry $G$, restrykcja $s|_G$ jest równowagą Nasha podgry $G$.

W grach o doskonałej informacji SPE pokrywa się z indukcją wsteczną. Jeśli gra nie posiada żadnych podgier właściwych, pojęcie SPE degraduje się do zwykłej równowagi Nasha.

Część II • Rozdział 4 Expected Utility Theory

Teoria Oczekiwanej Użyteczności von Neumanna-Morgensterna

4.1. Loterie pieniężne i postawy wobec ryzyka

Dla loterii pieniężnej $L = \begin{pmatrix} \$x_1 & \dots & \$x_n \\ p_1 & \dots & p_n \end{pmatrix}$ o wartości oczekiwanej $\mathbb{E}[L] = \sum p_i x_i$:

Awersja do ryzyka $$\$ \mathbb{E}[L] \succ L$$ Wklęsła funkcja użyteczności ($U'' < 0$).
Neutralność $$\$ \mathbb{E}[L] \sim L$$ Liniowa funkcja użyteczności ($U(m) = c \cdot m$).
Zamiłowanie do ryzyka $$L \succ \$ \mathbb{E}[L]$$ Wypukła funkcja użyteczności ($U'' > 0$).

4.2 - 4.3. Twierdzenia i Aksjomaty vNM

Twierdzenie 4.1 (vNM Representation, 1944): Preferencje decydenta nad loteriami $\mathcal{L}(O)$ spełniają aksjomaty vNM wtedy i tylko wtedy, gdy istnieje funkcja $U: O \to \mathbb{R}$ taka, że decydent maksymalizuje oczekiwaną użyteczność: $$L \succ L' \iff \mathbb{E}[U(L)] > \mathbb{E}[U(L')]$$

Twierdzenie 4.2 (Kardynalność): Funkcja użyteczności vNM jest wyznaczona jednoznacznie z dokładnością do dodatniej transformacji afinicznej: $V(o) = a U(o) + b$, gdzie $a > 0$. Cztery kluczowe aksjomaty: Zupełność i Przechodniość, Monotoniczność, Ciągłość (gwarantująca istnienie prawdopodobieństwa obojętności $o_i \sim p o_{\text{best}} + (1-p) o_{\text{worst}}$) oraz Niezależność/Zastępowalność.

Paradoks Allais (1953): Większość ludzi wybiera $A \succ B$ oraz $D \succ C$ w loteriach milionowych, bezpośrednio naruszając aksjomat niezależności vNM.
Paradoks Ellsberga (1961): Wybory w urnie z kulami o nieznanych proporcjach ujawniają awersję do niejednoznaczności (ambiguity aversion), której vNM nie potrafi odróżnić od czystego ryzyka.
Część II • Rozdział 5 Mixed Strategies & Rationalizability

Strategie Mieszane, Twierdzenie Nasha i Racjonalizowalność

5.1 - 5.3. Twierdzenie Johna Nasha i Zasada Obojętności

Twierdzenie 5.1 (John Nash, 1951): Każda skończona gra w postaci strategicznej o wypłatach kardynalnych posiada co najmniej jedną równowagę Nasha w strategiach mieszanych.

Twierdzenie 5.2 (Zasada Obojętności): Jeżeli $\sigma^*$ jest równowagą mieszaną, a strategie $s_{ij}, s_{ik}$ należą do nośnika $\text{supp}(\sigma_i^*)$, to: $$\Pi_i(s_{ij}, \sigma_{-i}^*) = \Pi_i(s_{ik}, \sigma_{-i}^*) = \Pi_i(\sigma^*)$$ Gracz nie uzyskuje żadnej premii z mieszania - jest obojętny między wszystkimi swoimi czystymi opcjami w nośniku! Randomizuje po to, by rywal nie odszedł od swojej strategii.

5.4. Dominacja przez strategie mieszane i Twierdzenie Pearce'a (1984)

W grach o wypłatach kardynalnych strategia czysta może być ściśle zdominowana przez strategię mieszaną, nawet jeśli żadna pojedyncza strategia czysta jej nie dominuje.

Twierdzenie 5.3 (David Pearce, 1984): W grze 2-osobowej czysta strategia $s_i$ nie jest najlepszą odpowiedzią na żaden stan przekonań o rywalu wtedy i tylko wtedy, gdy $s_i$ jest ściśle zdominowana przez pewną strategię mieszaną $\sigma_i$. Strategie, które przetrwają procedurę kardynalnego IDSDS, nazywamy strategiami racjonalizowalnymi.
Część II • Rozdział 6 Dynamic Games with Cardinal Payoffs

Strategie Behawioralne i Twierdzenie Kuhna

6.1. Strategie mieszane a behawioralne

W grach ekstensywnych strategia mieszana wymaga przypisania prawdopodobieństw do każdego pełnego planu działania (co przy wielu węzłach prowadzi do eksplozji kombinatorycznej, np. 54 strategie czyste = 53 parametry). Strategia behawioralna (Definicja 6.1) definiuje lokalne rozkłady prawdopodobieństwa niezależnie w każdym zbiorze informacyjnym (znacznie mniejsza liczba parametrów).

Twierdzenie 6.1 (Harold W. Kuhn, 1953): W grach w postaci ekstensywnej z doskonałą pamięcią (Perfect Recall), strategie mieszane i strategie behawioralne są w pełni równoważne: dla każdej strategii mieszanej istnieje strategia behawioralna indukująca identyczny rozkład prawdopodobieństwa na węzłach terminalnych.

6.3. Wady równowagi doskonałej w podgrach (SPE)

Jak demonstruje Bonanno w przykładzie z Rysunku 6.12, w grach bez właściwych podgier SPE pokrywa się z równowagą Nasha. W efekcie SPE dopuszcza profile, w których gracz poza ścieżką równowagi planuje zagrać akcję ściśle zdominowaną w swoim zbiorze informacyjnym. Aby wyeliminować takie patologie, konieczne są głębsze uszczegółowienia (refinements) oparte na systemach przekonań.

Część III • Rozdział 7 Knowledge & Common Knowledge

Epistemiczna Teoria Gier: Wiedza i Wspólna Wiedza Aumanna

7.1. Przestrzeń stanów i Operator Wiedzy $K$

Niech $W$ będzie skończonym zbiorem stanów świata, a $\mathcal{I}_i$ partycją informacyjną gracza $i$. Gracz $i$ wie, że zaszło zdarzenie $E \subseteq W$, gdy jego komórka informacji mieści się w $E$: $\mathcal{I}_i(w) \subseteq E$. Operator wiedzy $K_i: 2^W \to 2^W$ spełnia aksjomaty S5 logiki modalnej:

Aksjomat Prawdy (T): $K_i E \subseteq E$
Wiedza nie może być fałszywa.
Pozytywna Introspekcja (4): $K_i E \subseteq K_i K_i E$
Jeśli gracz wie $E$, to wie, że wie $E$.
Negatywna Introspekcja (5): $\neg K_i E \subseteq K_i \neg K_i E$
Jeśli gracz nie wie $E$, wie, że nie wie $E$.
Koniunkcja: $K_i(E \cap F) = K_i E \cap K_i F$
Wiedza o iloczynie to iloczyn wiedzy.

7.3. Definicja i Twierdzenie Aumanna o Wspólnej Wiedzy

Zdarzenie $E$ jest wspólną wiedzą (Common Knowledge), gdy każdy wie $E$, każdy wie, że każdy wie $E$, i tak w nieskończoność: $$CKE = K_1 E \cap K_2 E \cap K_1 K_2 E \cap K_2 K_1 E \cap \dots$$

Twierdzenie 7.1 (Robert Aumann, 1976): Zdarzenie $E$ jest wspólną wiedzą w stanie $w$ wtedy i tylko wtedy, gdy cała komórka partycji wspólnej wiedzy $\mathcal{I}_{CK}(w)$ zawiera się w $E$: $$w \in CKE \iff \mathcal{I}_{CK}(w) \subseteq E$$ gdzie $\mathcal{I}_{CK}$ jest najdrobniejszym wspólnym zgrubieniem (finest common coarsening) indywidualnych partycji informacyjnych!
Część III • Rozdział 8 Probabilistic Beliefs & Belief Revision

Przekonania, Aktualizacja Bayesa i Twierdzenie o Zgodzie

8.1 - 8.2. Pewność a wiedza i Reguła Bayesa

Bonanno podkreśla kardynalną różnicę: wiedza implikuje prawdę ($KE \subseteq E$), podczas gdy pewność ($P(E) = 1$) dopuszcza błąd poznawczy (można być w 100% pewnym fałszywego zdarzenia). Dla zdarzeń niespodziewanych z $P(E) > 0$ stosujemy standardową regułę Bayesa: $$P(E|F) = \frac{P(F|E)P(E)}{P(F)}$$

8.3. Teoria Rewizji Przekonań AGM (Alchourrón, Gärdenfors, Makinson, 1985)

Co zrobić, gdy agent otrzymuje informację zaskakującą, o zerowym prawdopodobieństwie a priori ($P(E) = 0$)? Dzielenie przez zero w formule Bayesa jest niedozwolone. Odpowiedź daje aksjomatyczna teoria AGM. Zgodnie z Twierdzeniem Grove'a (1988) i Bonanno (2009), racjonalna rewizja przekonań jest reprezentowana przez porządek wiarygodności $\precsim$ (total preorder na stanach). Po nadejściu informacji $E$, agent uznaje za możliwe wyłącznie stany najbardziej wiarygodne wewnątrz podzbioru $E$.

8.4 - 8.5. Wspólny rozkład a priori i Twierdzenie o Braku Zgody na Niezgodę

Twierdzenie 8.1 (Agreement Theorem; Robert Aumann, 1976): Jeżeli dwaj racjonalni gracze posiadają wspólny rozkład a priori (Common Prior Assumption) i w pewnym stanie $w$ jest wspólną wiedzą, że Gracz 1 przypisuje zdarzeniu $E$ prawdopodobieństwo $p$, a Gracz 2 prawdopodobieństwo $q$, to: $$p = q$$ Dwaj racjonalni gracze o wspólnych przekonaniach wyjściowych nie mogą zgodzić się na niezgodę (cannot agree to disagree)!
Część III • Rozdział 9 Common Knowledge of Rationality

Wspólna Wiedza o Racjonalności (CKR) w Grach

9.1 - 9.2. Epistemiczna charakteryzacja eliminacji dominacji

W epistemicznym modelu gry każdy stan $w$ przypisuje graczom przekonania oraz wybrane strategie $\sigma_i(w)$. Gracz jest racjonalny w stanie $w$, jeśli jego wybór jest najlepszą odpowiedzią na jego subiektywne przekonania. Niech $R$ oznacza zdarzenie, że wszyscy gracze są racjonalni.

Twierdzenie 9.1: Jeśli w stanie $w$ zachodzi wspólna wiedza o racjonalności ($w \in CKR$), to profil strategii $\sigma(w)$ musi przetrwać procedurę iteracyjnej eliminacji strategii ściśle zdominowanych (IDSDS).
Twierdzenie 9.2: Każdy profil strategii, który przetrwa procedurę IDSDS, może być zrealizowany w pewnym modelu epistemicznym w stanie, w którym zachodzi $CKR$.
Kluczowy Wniosek Teoretyczny: Wspólna wiedza o racjonalności ($CKR$) NIE implikuje równowagi Nasha! Równowaga Nasha wymaga nie tylko racjonalności i wspólnej wiedzy o niej, ale także zgodności przekonań (prawidłowego przewidywania wyborów rywala).
Część IV • Rozdział 10 Weak Sequential Equilibrium

Słaba Równowaga Sekwencyjna (WSE) i Granice Uszczegółowień

Aby wyeliminować patologie SPE, definiuje się ocenę $(\sigma, \mu)$, gdzie $\sigma$ to strategie behawioralne, a $\mu$ to system przekonań na węzłach zbiorów informacyjnych. Słaba równowaga sekwencyjna (WSE) wymaga:

  1. Racjonalności sekwencyjnej: W każdym zbiorze informacyjnym wybór gracza jest optymalny względem jego przekonań $\mu$ i przyszłych strategii.
  2. Aktualizacji bayesowskiej w zbiorach osiąganych: $\mu(x) = \frac{\mathbb{P}_{root,\sigma}(x)}{\mathbb{P}_{root,\sigma}(H)}$ dla $\mathbb{P}(H) > 0$.
Twierdzenie 10.1 & Paradoks WSE: Każde WSE indukuje równowagę Nasha. Jednak WSE nie uszczegóławia SPE! Ponieważ w nieosiąganych podgrach przekonania mogą być dowolne, gracz w nieosiąganej podgrze może wybrać strategię niebędącą równowagą Nasha owej podgry.
Część IV • Rozdział 11 Sequential Equilibrium

Równowaga Sekwencyjna Krepsa-Wilsona (1982)

David Kreps i Robert Wilson (1982) zaproponowali rozwiązanie problemu dowolności przekonań poza ścieżką gry poprzez warunek spójności (KW-consistency): Ocena $(\sigma, \mu)$ jest spójna, jeśli istnieje ciąg strategii całkowicie mieszanych $\sigma_n \to \sigma$ taki, że wyznaczone jednoznacznie z reguły Bayesa przekonania $\mu_n$ zbiegają do $\mu$: $$\lim_{n \to \infty} \sigma_n = \sigma, \quad \lim_{n \to \infty} \mu_n = \mu$$

Twierdzenie 11.1 (Kreps & Wilson, 1982): Każda równowaga sekwencyjna jest równowagą doskonałą w podgrach (SPE) oraz słabą równowagą sekwencyjną (WSE). Zachodzi ścisła hierarchia: $$\text{Równowaga Sekwencyjna} \subset (\text{SPE} \cap \text{WSE}) \subset \text{Równowaga Nasha}$$

Krytyka pojęcia: Kreps, Wilson, Osborne i Rubinstein wskazywali, że wymóg zbieżności ciągów zaburzonych jest sztuczną, czysto techniczną konstrukcją topologiczną bez przejrzystej interpretacji poznawczej.

Część IV • Rozdział 12 Perfect Bayesian Equilibrium

Doskonała Równowaga Bayesowska i Przełom Bonanno (2015)

Giacomo Bonanno dokonuje genialnej rekonstrukcji pojęcia równowagi w grach dynamicznych, opierając je na podejściu historycznym (historiach akcji $h \in H$) oraz porządkach wiarygodności teorii AGM.

Twierdzenie 12.5 (Giacomo Bonanno, 2015): Zamknięcie Luki Teoretycznej

Ocena $(\sigma, \mu)$ w skończonej grze ekstensywnej jest Równowagą Sekwencyjną Krepsa-Wilsona wtedy i tylko wtedy, gdy:

  1. Jest Doskonałą Równowagą Bayesowską (PBE) racjonalizowaną przez porządek wiarygodności $\precsim$,
  2. Porządek $\precsim$ spełnia warunek mierzalności wyborów (Choice Measurability - CM): odległości wiarygodności między historiami są zachowywane przy dodaniu tej samej akcji, oraz
  3. Ocena jest jednorodnie bayesowska (Uniformly Bayesian) względem $\precsim$.

Wynik ten całkowicie eliminuje konieczność konstruowania nieskończonych ciągów zaburzonych strategii i granic topologicznych, zastępując je czystą algebrą rewizji przekonań!

Implementacja Algorytmów w Pythonie (GameTheoryCore)

Poniższy skrypt implementuje kluczowe procedury z podręcznika Bonanno: obliczanie równowag czystych i mieszanych dla gier $2 \times 2$ oraz eliminację zdominowanych strategii w czystym Pythonie bez zewnętrznych zależności. 

# GameTheoryCore - Bonanno Solvers in Python
from typing import Dict, List, Tuple, Optional

class MatrixGame2x2:
    """
    2-player 2x2 game solver with Best Reply analysis,
    pure Nash equilibria and mixed Nash equilibria.
    Payoffs:
      R1: (tl1, tl2) vs (tr1, tr2)
      R2: (bl1, bl2) vs (br1, br2)
    """
    def __init__(self, tl: Tuple[float, float], tr: Tuple[float, float],
                 bl: Tuple[float, float], br: Tuple[float, float]):
        self.tl1, self.tl2 = tl
        self.tr1, self.tr2 = tr
        self.bl1, self.bl2 = bl
        self.br1, self.br2 = br

    def pure_nash_equilibria(self) -> List[str]:
        equilibria = []
        # P1 best replies in columns
        p1_c1 = [self.tl1 >= self.bl1, self.bl1 >= self.tl1] # [TL, BL]
        p1_c2 = [self.tr1 >= self.br1, self.br1 >= self.tr1] # [TR, BR]

        # P2 best replies in rows
        p2_r1 = [self.tl2 >= self.tr2, self.tr2 >= self.tl2] # [TL, TR]
        p2_r2 = [self.bl2 >= self.br2, self.br2 >= self.bl2] # [BL, BR]

        if p1_c1[0] and p2_r1[0]: equilibria.append("(R1, C1)")
        if p1_c2[0] and p2_r1[1]: equilibria.append("(R1, C2)")
        if p1_c1[1] and p2_r2[0]: equilibria.append("(R2, C1)")
        if p1_c2[1] and p2_r2[1]: equilibria.append("(R2, C2)")
        return equilibria

    def mixed_nash_equilibrium(self) -> Optional[Dict[str, float]]:
        # P2 indifference for P1 mixed strategy p:
        # p*tl2 + (1-p)*bl2 = p*tr2 + (1-p)*br2
        denom_p = (self.tl2 - self.tr2) - (self.bl2 - self.br2)
        num_p = self.br2 - self.bl2
        
        # P1 indifference for P2 mixed strategy q:
        # q*tl1 + (1-q)*tr1 = q*bl1 + (1-q)*br1
        denom_q = (self.tl1 - self.bl1) - (self.tr1 - self.br1)
        num_q = self.br1 - self.tr1

        if denom_p == 0 or denom_q == 0:
            return None
        
        p = num_p / denom_p
        q = num_q / denom_q

        if 0 < p < 1 and 0 < q < 1:
            eu1 = self.tl1 * q + self.tr1 * (1 - q)
            eu2 = self.tl2 * p + self.bl2 * (1 - p)
            return {"p_star": p, "q_star": q, "EU1": eu1, "EU2": eu2}
        return None

if __name__ == "__main__":
    # Test on Matching Pennies
    mp = MatrixGame2x2((1, -1), (-1, 1), (-1, 1), (1, -1))
    print("Matching Pennies Pure Nash:", mp.pure_nash_equilibria()) # []
    print("Matching Pennies Mixed Nash:", mp.mixed_nash_equilibrium()) # p=0.5, q=0.5
