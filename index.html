Rozdział 0: Geneza, Zakres i Paradygmat Homo Rationalis

Teoria gier dostarcza formalnego języka do modelowania i analizy sytuacji interaktywnych - sytuacji, w których decyzje wielu podmiotów (zwanych graczami) wspólnie wyznaczają końcowy rezultat. Rozwój dyscypliny zapoczątkowali na początku XX wieku matematycy Ernst Zermelo (1913) oraz John von Neumann (1928). Kamieniem milowym stała się monografia Johna von Neumanna i Oskara Morgensterna Theory of Games and Economic Behavior (1944), po której nastąpiły przełomowe prace Johna Nasha (1950-1951) i Lloyda Shapleya (1953).

Wpływ teorii gier na ekonomię i nauki społeczne został uhonorowany wieloma Nagrodami Nobla: w 1994 r. (John Nash, John Harsanyi, Reinhard Selten), w 2005 r. (Robert Aumann, Thomas Schelling), w 2007 r. (Leonid Hurwicz, Eric Maskin, Roger Myerson) oraz w 2012 r. (Lloyd Shapley, Alvin Roth). Praktycznym triumfem teorii stało się m.in. zaprojektowanie w 1994 r. przez Federalną Komisję Łączności (FCC) aukcji pasma radiowego o wartości 7 miliardów dolarów.

„Mówiąc krótko, teoria gier i ekonomia zajmują się interaktywnym zachowaniem Homo rationalis - człowieka racjonalnego. Homo rationalis to gatunek, który zawsze działa zarówno celowo, jak i logicznie, posiada ściśle określone cele, jest motywowany wyłącznie pragnieniem zbliżenia się do tych celów tak bardzo, jak to możliwe, i ma zdolności kalkulacyjne wymagane, aby to uczynić.”
- Robert Aumann (1985, s. 35)

Gry Kooperacyjne

Zakładają możliwość bezpośredniej komunikacji, formowania trwałych koalicji i zawierania prawnie wiążących umów (binding agreements). Wykorzystywane m.in. do analizy systemów głosowania, wartości Shapleya i sprawiedliwego podziału kosztów.

Gry Niekooperacyjne (Zakres Podręcznika)

Analizują sytuacje, w których gracze nie mogą się komunikować lub porozumienia nie mogą być prawnie egzekwowane (np. zakaz karteli i zmów cenowych w prawie antymonopolowym). Wszelkie porozumienia muszą być samoegzekwujące się (self-enforcing).

Rozdział 1: Ordinal Games in Strategic Form

1.1. Ramki gry a gry (Game Frames and Games)

Sytuacja decyzyjna przed zdefiniowaniem motywacji graczy to ramka gry w postaci strategicznej (Definicja 1.1):

$$\langle I, (S_1, S_2, \dots, S_n), O, f \rangle$$

gdzie $I = \{1, \dots, n\}$ to zbiór graczy ($n \ge 2$), $S_i$ to zbiór strategii gracza $i$, $S = S_1 \times \dots \times S_n$ to przestrzeń profili strategii, $O$ to zbiór możliwych rezultatów fizycznych, a $f: S \to O$ funkcją przypisującą profilowi $s = (s_1, \dots, s_n)$ rezultat $f(s) \in O$.

Przykład telewizyjny Split or Steal (Golden Balls): Wynik to kwoty pieniężne. Jeśli Sarah jest egoistyczna i chciwa, woli więcej pieniędzy niż mniej ($o_3 \succ o_1 \succ o_2 \sim o_4$). Jeśli jednak Sarah kieruje się sprawiedliwością i życzliwością, jej ranking to $o_1 \succ o_3 \succ o_2 \succ o_4$. Sama ramka nie determinuje decyzji - racjonalny wybór zależy od relacji preferencji!

Preferencje $\succsim_i$ muszą być zupełne i przechodnie. Funkcja $U_i: O \to \mathbb{R}$ jest porządkową funkcją użyteczności (Definicja 1.2), gdy $U_i(o) > U_i(o') \iff o \succ_i o'$ oraz $U_i(o) = U_i(o') \iff o \sim_i o'$. Zastąpienie preferencji funkcjami użyteczności daje zredukowaną postać gry (Definicja 1.3): $\langle I, (S_1, \dots, S_n), (\pi_1, \dots, \pi_n) \rangle$, gdzie funkcja wypłaty wynosi $\pi_i(s) = U_i(f(s))$.

1.2. Dominacja ścisła i słaba (Strict and Weak Dominance)

Niech $s_{-i} \in S_{-i}$ oznacza podprofil wyborów rywali gracza $i$. Zgodnie z Definicją 1.4:

  • Ścisła dominacja: $a$ ściśle dominuje $b$, jeśli $\forall s_{-i} \in S_{-i}: \pi_i(a, s_{-i}) > \pi_i(b, s_{-i})$.
  • Słaba dominacja: $a$ słabo dominuje $b$, jeśli $\forall s_{-i} \in S_{-i}: \pi_i(a, s_{-i}) \ge \pi_i(b, s_{-i})$ oraz $\exists \bar{s}_{-i}: \pi_i(a, \bar{s}_{-i}) > \pi_i(b, \bar{s}_{-i})$.
  • Równoważność: $a$ jest równoważna $b$, jeśli $\forall s_{-i} \in S_{-i}: \pi_i(a, s_{-i}) = \pi_i(b, s_{-i})$.

Definicja 1.5: Strategia $a$ jest ściśle dominująca, jeśli ściśle dominuje każdą inną strategię gracza $i$. Strategia jest słabo dominująca, jeśli każdą inną strategię słabo dominuje lub jest jej równoważna. W grze może istnieć co najwyżej jedna strategia ściśle dominująca dla danego gracza.

Dylemat Więźnia i Efektywność Pareto (Definicja 1.7): Rezultat $o$ jest ściśle Pareto-lepszy od $o'$, jeśli $\forall i: o \succ_i o'$. W Dylemacie Więźnia indywidualna racjonalność zmusza obu graczy do wybrania strategii ściśle dominującej (zdrada/nadgodziny), co generuje wynik ściśle gorszy w sensie Pareto od wzajemnej współpracy.

1.3. Aukcja drugiej ceny Vickreya (Theorem 1.1)

Twierdzenie 1.1 (William Vickrey, 1961)

W zapieczętowanej aukcji drugiej ceny z $n \ge 2$ graczami, jeśli gracz $i$ jest egoistyczny i chciwy (jego wycena przedmiotu to $v_i > 0$, zysk przy wygranej wynosi $v_i - p$, a przy przegranej 0), to zgłoszenie oferty równej prawdziwej wycenie: $$b_i = v_i$$ jest strategią słabo dominującą.

Dowód (Appendix 1.A): Niech $b^{\max}_{-i}$ będzie najwyższą ofertą rywali. Przypadek 1: $b^{\max}_{-i} \le v_i$. Oferta $b_i = v_i$ wygrywa i daje wypłatę $v_i - b^{\max}_{-i} \ge 0$. Każda inna oferta $b_i' \ge b^{\max}_{-i}$ wygrywa i płaci dokładnie tyle samo. Każda oferta $b_i' < b^{\max}_{-i}$ przegrywa i daje 0. Zatem żadna oferta nie daje więcej niż $v_i$. Przypadek 2: $b^{\max}_{-i} > v_i$. Oferta $b_i = v_i$ przegrywa i daje 0. Każda oferta $b_i' \le b^{\max}_{-i}$ również daje 0. Każda oferta $b_i' > b^{\max}_{-i}$ wygrywa, lecz płaci $b^{\max}_{-i}$, co generuje stratę $v_i - b^{\max}_{-i} < 0$. W obu przypadkach licytowanie $v_i$ jest optymalne.

1.4. Mechanizm Pivotowy Clarke'a (Theorem 1.2)

Społeczność decyduje o projekcie publicznym o koszcie $C$, gdzie każdy ponosi z góry ustalony koszt $c_i$ ($\sum c_i = C$). Projekt jest efektywny w sensie Pareto wtedy i tylko wtedy, gdy $\sum_{i=1}^n v_i > C$. Wyceny $v_i$ są jednak informacją prywatną.

Twierdzenie 1.2 (Edward Clarke, 1971)

W mechanizmie pivotowym każdy deklaruje kwotę $w_i$. Projekt jest realizowany, gdy $\sum w_j > C$. Gracz jest pivotowy, jeśli jego usunięcie ze społeczności zmieniłoby decyzję o projekcie. Jeśli gracz jest pivotowy, płaci podatek w wysokości szkody nałożonej na resztę społeczeństwa: $$t_i = \left| \sum_{j \ne i} w_j - \sum_{j \ne i} c_j \right|$$ Dla każdego gracza prawdomówność ($w_i = v_i$) jest strategią słabo dominującą.

1.5 - 1.7. Eliminacja Iteracyjna, Równowaga Nasha i Duopol Cournota

IDSDS (1.5.1): Eliminacja strategii ściśle zdominowanych prowadzi do zbioru $G^\infty$. W grach skończonych porządek eliminacji jest nieistotny (Remark 1.5). W IDWDS (1.5.2) kolejność ma znaczenie, dlatego w każdym kroku należy eliminować symetrycznie wszystkie strategie słabo zdominowane.

Równowaga Nasha (Definicja 1.9 & 1.10): Profil $s^*$ jest równowagą Nasha, gdy dla każdego gracza $s_i^*$ jest najlepszą odpowiedzią na $s_{-i}^*$. W tabelach dwuosobowych stosujemy metodę podkreślania maksymalnej wypłaty w kolumnach dla Gracza 1 i w wierszach dla Gracza 2.

Duopol Cournota (1.7): Rynek z popytem $P = a - b(q_1 + q_2)$ i kosztami $C_i(q_i) = c q_i$. Zyski: $\pi_1(q_1, q_2) = (a - c - b q_1 - b q_2) q_1$. Różniczkując: $$\frac{\partial \pi_1}{\partial q_1} = a - c - 2b q_1 - b q_2 = 0 \implies q_1 = \frac{a - c - b q_2}{2b}$$ Symetryczne rozwiązanie układu równań reakcji daje unikalną równowagę Nasha: $$q_1^* = q_2^* = \frac{a - c}{3b}, \quad P^* = \frac{a + 2c}{3}, \quad \pi_1^* = \pi_2^* = \frac{(a - c)^2}{9b}$$

Wyróżnione Zadanie 1.23 (Posner's Nuisance Rule): Zakład chemiczny Mondevil o zysku $\Pi > 0$ zanieczyszcza rzekę, wyrządzając szkodę rybołówstwu $L > 0$. W sądzie strony składają deklaracje $x, y \ge 0$. Jeśli $y > x$, fabryka zostaje zamknięta; jeśli $x \ge y$, fabryka działa i płaci rybakom $y$. Prawdomówność fabryki ($x = \Pi$) jest strategią słabo dominującą, lecz rybacy mają motywację do blefu ($y > L$). W równowadze z $\Pi > L$ fabryka działa, a z $\Pi < L$ zostaje zamknięta, co gwarantuje efektywność Pareto.

Rozdział 2: Dynamiczne Gry o Doskonałej Informacji

2.1 - 2.2. Drzewa decyzyjne i Algorytm Indukcji Wstecznej

Drzewo ukorzenione posiada korzeń (indegree 0), węzły decyzyjne $D$, węzły terminalne $Z$ oraz funkcję przypisania graczy $\iota: D \to I$. W grach o doskonałej informacji każdy węzeł tworzy jednoelementowy zbiór informacyjny.

Algorytm indukcji wstecznej (Definicja 2.3): Krok 1: Wybierz węzeł decyzyjny $x$, którego wszyscy następcy są oznaczeni wektorem wypłat. Gracz $\iota(x)$ wybiera akcję maksymalizującą jego wypłatę. Węzeł $x$ otrzymuje wektor wypłat tego następcy. Krok 2: Powtarzaj procedurę, aż korzeń zostanie oznaczony.

Strategia jako kompletny plan (Definicja 2.4): Strategia gracza musi określać wybór dla każdego węzła decyzyjnego tego gracza w drzewie, nawet jeśli z powodu wcześniejszych posunięć węzeł ten nigdy nie zostanie osiągnięty.

Twierdzenie 2.1: Każde rozwiązanie indukcji wstecznej jest równowagą Nasha powiązanej postaci strategicznej. Jednak w postaci strategicznej istnieją dodatkowe równowagi Nasha, które opierają się na niewiarygodnych groźbach (Incredible Threats) - np. groźba wojny cenowej w grze wejścia na rynek, której monopolista po fakcie wejścia nigdy by nie zrealizował!
Paradoks Sieci Sklepów Seltena (1978)

Monopolista operuje w $m$ miastach przeciwko $m$ niezależnym pretendentkom. W ostatnim mieście $m$ nikt już nie obserwuje gry, więc uległość (zysk 2) jest lepsza od walki (zysk 0). Pretendentka w mieście $m-1$ wie, że w mieście $m$ monopolista ulegnie, więc walka w $m-1$ nie kupi reputacji. Indukcja wsteczna zwija grę: monopolista ulega we wszystkich $m$ miastach, mimo że intuicja biznesowa nakazywałaby agresywną obronę!

Uogólnienie Twierdzenia Zermelo (1913)

Twierdzenie 2.2: W każdej skończonej dwuosobowej grze o doskonałej informacji typu wygrana-przegrana jeden z graczy ma strategię wygrywającą (np. gra liczbowa Race to 100).
Twierdzenie 2.3: W grach dopuszczających remis (szachy, warcaby, kółko i krzyżyk) zachodzi dokładnie jedna z trzech możliwości: 1. Gracz 1 ma strategię wygrywającą, 2. Gracz 2 ma strategię wygrywającą, lub 3. Obaj gracze mają strategie gwarantujące co najmniej remis.

Rozdział 3: Ogólne Gry Dynamiczne i SPE

3.1. Doskonała pamięć (Perfect Recall - Definicja 3.1)

W grach z niedoskonałą informacją zbiór informacyjny $D$ grupuje węzły, których gracz nie potrafi rozróżnić. Warunek Perfect Recall wymaga, aby:

  1. Dostępne akcje były identyczne we wszystkich węzłach tego samego zbioru informacyjnego.
  2. Żaden węzeł w zbiorze informacyjnym nie był poprzednikiem innego węzła w tym samym zbiorze.
  3. Gracz pamiętał wszystkie swoje wcześniejsze wybory i informacje: jeśli $x$ poprzedza $y$ i gracz wybrał $a$ w $x$, to każdy węzeł w zbiorze informacyjnym $y$ musi mieć poprzednika w zbiorze $x$, z którego wychodzi akcja $a$.

3.3 - 3.4. Podgry Właściwe i Równowaga Doskonała w Podgrach (SPE)

Podgra właściwa (Definicja 3.3): Drzewo potomne rozpoczynające się w węźle pojedynczym (singleton), które nie rozcina żadnego zbioru informacyjnego w grze.

Definicja 3.5 (Reinhard Selten, 1965): Profil strategii $s$ jest równowagą doskonałą w podgrach (SPE), jeśli jest równowagą Nasha całej gry oraz w każdej właściwej podgrze $G$ restrykcja $s|_G$ jest równowagą Nasha owej podgry.

Algorytm SPE (Definicja 3.6): Zwijamy podgry minimalne zastępując je wektorami wypłat z równowag Nasha tych podgier. Jeśli podgra nie ma równowagi Nasha w strategiach czystych, w grze porządkowej SPE może nie istnieć!

3.5. Ruchy Losowe Natury i Loterie

Natura jest fikcyjnym graczem bez wypłat, podejmującym ruchy z obiektywnym prawdopodobieństwem. Rezultaty stają się loteriami. Przy neutralności wobec ryzyka gracze oceniają loterie wartością oczekiwaną $\mathbb{E}[L] = \sum p_i x_i$. Przykładem jest gra w wymianę kopert ($100, $200, $300), gdzie brak ostrożności prowadzi do klątwy zwycięzcy (Winner's Curse).

Rozdział 4: Teoria Oczekiwanej Użyteczności von Neumanna-Morgensterna

4.1 - 4.2. Twierdzenia o Reprezentacji Użyteczności vNM

Gdy rezultaty są niepewne, potrzebujemy kardynalnej teorii wyboru. Dla loterii $L = \begin{pmatrix} o_1 & \dots & o_m \\ p_1 & \dots & p_m \end{pmatrix}$ zbiór preferencji $\succsim$ nad $\mathcal{L}(O)$ nazywamy rankingiem vNM (Definicja 4.2).

Twierdzenie 4.1 (vNM, 1944) & Twierdzenie 4.2 (Transformacja Afiniczna)

Istnieje funkcja użyteczności $U: O \to \mathbb{R}$ taka, że: $$L \succ L' \iff \mathbb{E}[U(L)] > \mathbb{E}[U(L')]$$ Każda inna funkcja $V$ reprezentująca ten sam ranking vNM jest postaci $V(o) = a U(o) + b$, gdzie $a > 0$ i $b \in \mathbb{R}$. Użyteczność jest znormalizowana, gdy $U(o_{\text{worst}}) = 0$ oraz $U(o_{\text{best}}) = 1$.

Aksjomaty vNM (4.3): 1. Zupełność i przechodniość, 2. Monotoniczność ($p \ge q \iff p o_{\text{best}} + (1-p)o_{\text{worst}} \succsim q o_{\text{best}} + (1-q)o_{\text{worst}}$), 3. Ciągłość (istnienie $p \in [0,1]$ takiego, że $o_i \sim p o_{\text{best}} + (1-p)o_{\text{worst}}$), 4. Niezależność/Zastępowalność (zastąpienie rezultatu obojętną loterią zachowuje ranking).

Paradoks Allais (1953): Wybór $A \succ B$ oraz $D \succ C$ dowodzi systematycznego naruszania aksjomatu niezależności u ludzi.
Paradoks Ellsberga (1961): Brak wiedzy o proporcji kul w urnie wywołuje awersję do niejednoznaczności, nieuchwytną w teorii vNM.
Część II • Rozdział 5 Mixed Strategies • Strony 186-223

Rozdział 5: Strategie Mieszane w Grach Strategicznych

5.1 - 5.3. Twierdzenie Nasha i Zasada Obojętności

Strategia mieszana to rozkład $\sigma_i \in \Delta(S_i)$. Twierdzenie 5.1 (John Nash, 1951): Każda skończona gra w postaci strategicznej o wypłatach kardynalnych posiada co najmniej jedną równowagę Nasha w strategiach mieszanych.

Twierdzenie 5.2 (Bishop / Zasada Obojętności): Jeżeli $\sigma^*$ jest równowagą mieszaną, to dla każdego gracza $i$ i dowolnych dwóch czystych strategii $s_{ij}, s_{ik} \in \text{supp}(\sigma_i^*)$ zachodzi: $$\Pi_i(s_{ij}, \sigma_{-i}^*) = \Pi_i(s_{ik}, \sigma_{-i}^*) = \Pi_i(\sigma^*)$$ Gracz nie uzyskuje wyższej wypłaty ze strategii w nośniku - jest między nimi obojętny! Miesza strategie, aby uczynić obojętnym swojego rywala.

5.4. Dominacja przez strategie mieszane i Twierdzenie Pearce'a (1984)

Czysta strategia może być ściśle zdominowana przez strategię mieszaną, mimo że nie jest zdominowana przez żadną strategię czystą. Twierdzenie 5.3 (Pearce, 1984): W grze 2-osobowej czysta strategia $s_i$ nie jest najlepszą odpowiedzią na żadną strategię rywala $\iff$ $s_i$ jest ściśle zdominowana przez pewną strategię mieszaną $\sigma_i$. Strategie, które przetrwają procedurę kardynalnego IDSDS, nazywamy strategiami racjonalizowalnymi.

Wyróżnione Zadanie 5.15 (Volunteer's Dilemma / Drowning Dog): $n$ pływaków widzi tonącego psa w rzece Sacramento. Przeżycie psa jest warte $v$, koszt skoku do lodowatej wody wynosi $c$ ($0 < c < v$). W symetrycznej równowadze mieszanej każdy skacze z prawdopodobieństwem $p = 1 - (c/v)^{\frac{1}{n-1}}$. Prawdopodobieństwo, że nikt nie skoczy i pies utonie wynosi $(c/v)^{\frac{n}{n-1}}$ - rośnie ono wraz ze wzrostem liczby pływaków! Klasyczny dowód efektu widza (bystander effect).
Część II • Rozdział 6 Dynamic Cardinal Games • Strony 224-251

Rozdział 6: Gry Dynamiczne o Wypłatach Kardynalnych i Twierdzenie Kuhna

6.1. Strategie behawioralne a mieszane (Twierdzenie Kuhna 1953)

W postaci ekstensywnej strategia behawioralna definiuje rozkłady prawdopodobieństwa niezależnie w każdym zbiorze informacyjnym. Twierdzenie 6.1 (Harold W. Kuhn, 1953): W grach o doskonałej pamięci (Perfect Recall), strategie mieszane i behawioralne są w pełni równoważne co do rozkładów na węzłach końcowych.

Wady SPE (6.3): W grze z Rysunku 6.12 brak właściwych podgier sprawia, że SPE dopuszcza profile, w których gracz poza ścieżką gry wybiera akcję ściśle zdominowaną w swoim zbiorze informacyjnym. Wymaga to wprowadzenia ocen $(\sigma, \mu)$ i racjonalności sekwencyjnej!

Część III • Rozdział 7 Epistemic Game Theory • Strony 253-288

Rozdział 7: Wiedza i Wspólna Wiedza Aumanna

7.1. Modele Kripkego i Operator Wiedzy $K$

Niech $W$ będzie zbiorem stanów świata, a $\mathcal{I}_i$ partycją informacyjną gracza $i$. Zdarzenie $E \subseteq W$. Gracz $i$ wie, że $E$ zaszło w stanie $w \iff \mathcal{I}_i(w) \subseteq E$. Operator $K_i: 2^W \to 2^W$ spełnia aksjomaty modalne S5: Prawda: $K_i E \subseteq E$, Spójność: $K_i E \cap K_i \neg E = \emptyset$, Pozytywna Introspekcja: $K_i E \subseteq K_i K_i E$, Negatywna Introspekcja: $\neg K_i E \subseteq K_i \neg K_i E$.

7.3. Twierdzenie Aumanna o Wspólnej Wiedzy (Theorem 7.1)

Wspólna wiedza to nieskończony iloczyn: $CKE = \bigcap_{m=1}^\infty K^m E$. Twierdzenie 7.1 (Robert Aumann, 1976): $w \in CKE \iff \mathcal{I}_{CK}(w) \subseteq E$, gdzie $\mathcal{I}_{CK}$ jest partycją osiągalności w grafie stanów (najdrobniejsze wspólne zgrubienie partycji graczy).

Część III • Rozdział 8 Beliefs & AGM Theory • Strony 289-331

Rozdział 8: Przekonania Probabilistyczne, Bayes i Teoria AGM

8.1 - 8.3. Rewizja Przekonań AGM i Porządki Wiarygodności

Dla zdarzeń z $P(E) = 0$ reguła Bayesa zawodzi. Z pomocą przychodzi teoria AGM (Alchourrón, Gärdenfors, Makinson, 1985). Twierdzenie 8.1 (Grove 1988, Bonanno 2009): Funkcja rewizji przekonań spełnia aksjomaty AGM wtedy i tylko wtedy, gdy jest racjonalizowana przez porządek wiarygodności $\precsim$ (total preorder na stanach $W$). Po nadejściu informacji $E$, agent uznaje za możliwe wyłącznie stany najbardziej wiarygodne w $E$.

8.5. Twierdzenie Aumanna o Braku Zgody na Niezgodę (Theorem 8.1)

Twierdzenie 8.1 (Agreement Theorem; Robert Aumann, 1976)

Niech $W$ będzie zbiorem stanów z dwoma agentami posiadającymi wspólny rozkład a priori (Common Prior). Jeśli w pewnym stanie $w$ jest wspólną wiedzą, że Gracz 1 przypisuje zdarzeniu $E$ prawdopodobieństwo $p$, a Gracz 2 prawdopodobieństwo $q$, to: $$p = q$$ Dwaj racjonalni gracze o tych samych przekonaniach wyjściowych nie mogą zgodzić się na niezgodę!

Rozdział 9: Wspólna Wiedza o Racjonalności (CKR)

W epistemicznym modelu gry (Definicja 9.1) każdemu stanowi $w$ przypisujemy strategie $\sigma_i(w)$ i przekonania $P_{i,w}$. Gracz jest racjonalny w stanie $w$ (Definicja 9.2), jeśli jego wybór maksymalizuje oczekiwaną wypłatę względem $P_{i,w}$.

Twierdzenie 9.1: Jeśli w stanie $w$ zachodzi $w \in CKR$, to wektor strategii $\sigma(w)$ musi przetrwać procedurę IDSDS.
Twierdzenie 9.2: Każdy profil strategii przetrwający IDSDS może być zrealizowany w pewnym modelu w stanie, w którym zachodzi $CKR$.
Część IV • Rozdział 10 Weak Sequential Equilibrium • Strony 354-388

Rozdział 10: Słaba Równowaga Sekwencyjna (WSE)

Ocena $(\sigma, \mu)$ (Definicja 10.1): Para strategii behawioralnych $\sigma$ oraz systemu przekonań $\mu$ na węzłach zbiorów informacyjnych. Ocena jest sekwencyjnie racjonalna (Definicja 10.2), gdy żaden gracz nie może poprawić swojej wypłaty poprzez jednostronną zmianę strategii w jakimkolwiek zbiorze informacyjnym. Wymóg aktualizacji bayesowskiej w osiąganych zbiorach (Definicja 10.4) tworzy Słabą Równowagę Sekwencyjną (WSE, Definicja 10.5).

Ograniczenie WSE (Figure 10.9 & 10.10): Każde WSE indukuje równowagę Nasha (Twierdzenie 10.1), lecz WSE nie uszczegóławia SPE! W nieosiąganych podgrach przekonania mogą być dowolne, co pozwala graczom wybierać akcje niebędące równowagą w podgrze.
Część IV • Rozdział 11 Sequential Equilibrium • Strony 389-417

Rozdział 11: Równowaga Sekwencyjna Krepsa-Wilsona (1982)

David Kreps i Robert Wilson (1982) zdefiniowali oceny spójne (KW-consistency, Definicja 11.1): istnieje ciąg strategii całkowicie mieszanych $\sigma_n \to \sigma$ ($\sigma_n(a) > 0$) taki, że wyznaczone z reguły Bayesa przekonania $\mu_n$ zbiegają do $\mu$: $$\lim_{n \to \infty} \sigma_n = \sigma, \quad \lim_{n \to \infty} \mu_n = \mu$$

Twierdzenie 11.1 & 11.2 (Kreps-Wilson): Każda równowaga sekwencyjna jest równowagą doskonałą w podgrach (SPE) oraz słabą równowagą sekwencyjną (WSE). Każda skończona gra o wypłatach kardynalnych posiada co najmniej jedną równowagę sekwencyjną! $$\text{Sequential Equilibrium} \subset (\text{SPE} \cap \text{WSE}) \subset \text{Nash}$$
Część IV • Rozdział 12 PBE & Bonanno's Theorem • Strony 418-469

Rozdział 12: PBE i Przełom Giacomo Bonanno (2015)

Giacomo Bonanno redefiniuje grę ekstensywną w oparciu o historie akcji $h \in H$ (Appendix 12.A) oraz porządek wiarygodności $\precsim$ na historiach (Definicja 12.1). Ocena $(\sigma, \mu)$ jest spójna w sensie AGM (Definicja 12.2), gdy akcje o dodatnim prawdopodobieństwie zachowują wiarygodność ($h \sim ha$), a przekonania $\mu$ skupiają się na historiach najbardziej wiarygodnych w danym zbiorze informacyjnym. Wymóg aktualizacji bayesowskiej tak długo, jak to możliwe (Definicja 12.3) definiuje Doskonałą Równowagę Bayesowską (PBE, Definicja 12.4).

Twierdzenie 12.5 (Giacomo Bonanno, 2015): Zamknięcie Luki Teoretycznej

Ocena $(\sigma, \mu)$ jest Równowagą Sekwencyjną Krepsa-Wilsona wtedy i tylko wtedy, gdy:

  1. Jest Doskonałą Równowagą Bayesowską (PBE) racjonalizowaną przez porządek wiarygodności $\precsim$,
  2. Porządek $\precsim$ spełnia warunek mierzalności wyborów (Choice Measurability - CM): odległości wiarygodności są niezmiennicze na dodanie wspólnej akcji ($F(h) - F(h') = F(ha) - F(h'a)$), oraz
  3. Ocena jest jednorodnie bayesowska (Uniformly Bayesian) względem $\precsim$.

Twierdzenie to stanowi jeden z największych triumfów współczesnej teorii gier: uwalnia definicję równowagi sekwencyjnej od topologicznych granic ciągów zaburzonych, zastępując je przejrzystym postulatem niezmienniczości proporcji wiarygodności w duchu logiki epistemicznej AGM!

Część V • Rozdział 15 Type Spaces vs Kripke States • Strony 557-575

Rozdział 15: Podejście Oparte na Przestrzeni Typów

Harsanyi sformalizował niepełną informację poprzez przestrzenie typów $T_i$ (gdzie typ koduje funkcję użyteczności oraz przekonania o typach rywali). Bonanno dowodzi, że podejście to jest w 100% równoważne interaktywnym strukturom stanów Kripkego $\Omega$ z logiki modalnej:

Stany $\to$ Typy: Każda komórka partycji gracza staje się pojedynczym typem $t_i$. Rozkład prawdopodobieństwa na komórce wyznacza przekonania typu o typach rywali.
Typy $\to$ Stany: Zbiorem stanów staje się iloczyn kartezjański typów $T = T_1 \times \dots \times T_n$. Dwa stany należą do tej samej komórki gracza $i \iff$ typ gracza $i$ jest w nich identyczny ($t_i = t_i'$).

Bonanno uogólnia tę równoważność na przypadek wartości współzależnych (Interdependent Values), gdzie użyteczność gracza zależy bezpośrednio od typów rywali: $U_i(t, s)$.

Implementacja Algorytmów w Pythonie (GameTheoryCore)

Poniższy skrypt implementuje kluczowe procedury z podręcznika Bonanno: obliczanie równowag czystych i mieszanych dla gier $2 \times 2$ oraz eliminację zdominowanych strategii w czystym Pythonie bez zewnętrznych zależności. 

# GameTheoryCore - Bonanno Solvers in Python
from typing import Dict, List, Tuple, Optional

class MatrixGame2x2:
    """
    2-player 2x2 game solver with Best Reply analysis,
    pure Nash equilibria and mixed Nash equilibria.
    Payoffs:
      R1: (tl1, tl2) vs (tr1, tr2)
      R2: (bl1, bl2) vs (br1, br2)
    """
    def __init__(self, tl: Tuple[float, float], tr: Tuple[float, float],
                 bl: Tuple[float, float], br: Tuple[float, float]):
        self.tl1, self.tl2 = tl
        self.tr1, self.tr2 = tr
        self.bl1, self.bl2 = bl
        self.br1, self.br2 = br

    def pure_nash_equilibria(self) -> List[str]:
        equilibria = []
        # P1 best replies in columns
        p1_c1 = [self.tl1 >= self.bl1, self.bl1 >= self.tl1] # [TL, BL]
        p1_c2 = [self.tr1 >= self.br1, self.br1 >= self.tr1] # [TR, BR]

        # P2 best replies in rows
        p2_r1 = [self.tl2 >= self.tr2, self.tr2 >= self.tl2] # [TL, TR]
        p2_r2 = [self.bl2 >= self.br2, self.br2 >= self.bl2] # [BL, BR]

        if p1_c1[0] and p2_r1[0]: equilibria.append("(R1, C1)")
        if p1_c2[0] and p2_r1[1]: equilibria.append("(R1, C2)")
        if p1_c1[1] and p2_r2[0]: equilibria.append("(R2, C1)")
        if p1_c2[1] and p2_r2[1]: equilibria.append("(R2, C2)")
        return equilibria

    def mixed_nash_equilibrium(self) -> Optional[Dict[str, float]]:
        # P2 indifference for P1 mixed strategy p:
        # p*tl2 + (1-p)*bl2 = p*tr2 + (1-p)*br2
        denom_p = (self.tl2 - self.tr2) - (self.bl2 - self.br2)
        num_p = self.br2 - self.bl2
        
        # P1 indifference for P2 mixed strategy q:
        # q*tl1 + (1-q)*tr1 = q*bl1 + (1-q)*br1
        denom_q = (self.tl1 - self.bl1) - (self.tr1 - self.br1)
        num_q = self.br1 - self.tr1

        if denom_p == 0 or denom_q == 0:
            return None
        
        p = num_p / denom_p
        q = num_q / denom_q

        if 0 < p < 1 and 0 < q < 1:
            eu1 = self.tl1 * q + self.tr1 * (1 - q)
            eu2 = self.tl2 * p + self.bl2 * (1 - p)
            return {"p_star": p, "q_star": q, "EU1": eu1, "EU2": eu2}
        return None

if __name__ == "__main__":
    # Test on Matching Pennies
    mp = MatrixGame2x2((1, -1), (-1, 1), (-1, 1), (1, -1))
    print("Matching Pennies Pure Nash:", mp.pure_nash_equilibria()) # []
    print("Matching Pennies Mixed Nash:", mp.mixed_nash_equilibrium()) # p=0.5, q=0.5
